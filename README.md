# 15 Puzzle

Mac用の15パズルです。空きマスの隣の数字をクリックし、左上から1〜15、右下を空きマスに並べます。

## 機能

- 必ず解ける配置で新しいゲームを開始
- 手数・経過時間・最少手数の記録
- ひとつ戻す（⌘Z）
- 新しいゲーム（⌘N）
- 完成判定とタイマー停止

タイマーは最初の移動から開始します。戻すと手数も戻ります。最少手数はこのルールに基づく個人記録です。

## 開発

FifteenPuzzle.xcodeprojをXcodeで開き、My Macを選んで⌘Rで実行します。⌘Uでテストします。macOS 14以降。ローカルの開発用署名です。

## 確認結果

Xcode 27.0でビルド・起動を確認。ロジック3件とUI起動1件、計4件のテストが成功しました。シャッフルは1000回検証しています。
